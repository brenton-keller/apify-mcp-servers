# MCP registry entries for brenton8907's Apify actors

Each directory holds a `server.json` that lists the actor's hosted MCP endpoint (`https://mcp.apify.com/?tools=<actor>`)
in the official MCP Registry under the `io.github.brenton-keller` namespace. Publishing runs in GitHub Actions with OIDC
on every push to `main`. Usage is billed pay-per-result by Apify.

- [prediction-markets-data](https://apify.com/brenton8907/prediction-markets-data)
- [product-hunt-data](https://apify.com/brenton8907/product-hunt-data)
